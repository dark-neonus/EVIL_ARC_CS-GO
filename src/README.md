# src/

Main source code directory for the SALR particle simulation project.

## Subdirectories

- **core/** — Core computational routines (integral solvers, DFT engine)
- **cuda/** — CUDA kernel implementations (GPU-accelerated computations)
- **cpu/** — CPU reference implementations (for benchmarking against CUDA)
- **math/** — Linear algebra and math utilities (vector/matrix operations)
- **utils/** — Helper utilities (I/O, grid setup, config parsing)
